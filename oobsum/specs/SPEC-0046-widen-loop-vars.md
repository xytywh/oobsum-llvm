# SPEC-0046 循环头只对本循环里被赋值的局部做 widening（嵌套循环的外层下标不丢界）

状态：已实现
来源：`run.py csa` 的漏报 LV3-09（**年内承诺**，期望 L2）：

```c
for (s = 0; s < RB_NUM; s++) {          /* 外层 */
    for (r = 0; r < SLOT_NUM; r++) {     /* 内层 */
        pucGrid[s * RB_NUM + r] = 0;
    }
}
```

`Dump=state`：外层循环体里 `s = [0, 7]:loop`，但内层循环头 `s = [0, +inf]:widen`——上升阶段外层的 `s` 每轮变大，传到内层循环头时被当成"循环里在变"
一起 widen 掉；内层并不改 `s`，回边带回的就是它自己，下降（收窄）阶段也拿不回来。访问 `s * 8 + r` 只剩类型范围 → 本函数记账、调用方不报。
06- A-16（widening）、A-33（不动点）、SPEC-0017 §2.1（上升 → 下降 2 遍）。

## 2. 设计

* DFS 时记下回边（指向栈上块的边）；每条回边 `src → head` 的自然循环体 = `head` 加上不经过 `head` 能走到 `src` 的块（反向走）。
* 每个循环头记"体内被赋值的局部"（循环体各块里指令的 `dst`：`set` / `load` / `call` / `havoc`）。同一个头有多条回边时取并。
* `WidenState` 只对这些局部做 widening；其余局部取汇合值（它们在这个循环里不变，值随外层收敛；外层循环头会 widen 它们）。
* 内存格照旧（汇合只保留两边相同的格）。

收敛：一个局部只在它被赋值的循环（及外层）的头上 widen，每个循环头上被赋值的局部都 widen，所以上升阶段照样有限步收敛；
另有 A-33 的每个循环头至多更新 20 次兜底（超过 → `partial:iter_limit`，函数声明处 SUSPECT）。

## 3. 对召回与误报的影响

**召回**：LV3-09 这类"外层下标乘常数 + 内层下标"的嵌套循环判出 L2（原来只在本函数记账、入口不报）。**误报减少**：嵌套循环里外层变量不再变成类型范围。

## 4. 实现位置

`core/Interp.cpp`：`Analyzer::Run`（回边、循环体、`loopVars`）、`WidenState`。

## 5. 测试

* lit `nested-loop.test`：LV3-09 同形的例子 → TP L2、TN SAFE；`Dump=state` 里内层循环头的 `s` 是 `[0, 7]`；对照：内层循环里改了外层变量（`s++` 在内层）→ 照旧 widen、不丢可靠性。
* `run.py csa`：LV3-09 从漏报变成通过；其它不回退。`replay.py`、`engine_check` 不回退。
