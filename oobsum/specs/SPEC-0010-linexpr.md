# SPEC-0010 线性式 `core/LinExpr`：规范形式、D-21 文本语法的解析与打印、条件、代换

状态：已实现（S6a）
来源：`STATUS.md` S6（WP2）；06- §5.3 D-20（接口符号与不透明项）、D-21（表达式语法、64 位系数、规范形式）、A-10（界里的线性式）、
A-61（代换表）；参考实现 `oobsum/cases/summaries/replay.py` 的 `Lin`、`Parser`、`mk_opaque`、`C`、`show_atom_le0`、`subst`
（06- A-92：C++ 要与它逐项一致）。

## 1. 要解决什么

摘要里的所有条件与末端都是线性式（`16*p1 - 12`、`ext(p0)`、`div(p0, 32)`）。引擎要能：读摘要里的表达式字符串、按规范形式比较两条表达式、
做加减与乘常数、把形参代换成实参（调用点第 ② 步）、把条件拆成"`L ≤ 0`"的原子（蕴含判定用）、再打印回同样的字符串。
这些都与 Clang 无关，放在 `core/`，与 `replay.py` 同语义，并用 104 份摘要里的全部表达式做金标准。

## 2. 设计

### 2.1 线性式与原子

`LinExpr` = 常数 `k` + Σ `c·原子`（`c` 为 int64，非零）。原子（`Atom`）六种：

| 原子 | 写法 | 说明 |
|---|---|---|
| 符号 | `p0`、`p1->ulLen`、`g:g_x`、调用方局部名 `i` | D-20 |
| 剩余字节 | `ext(p0)`、`ext(p0->pucBuf)` | D-20 |
| 不透明项 | `div(e, n)`、`mod(e, n)`、`wrap32(e)` / `wrap16(e)`、`mul(a, b)` | 内层是线性式；构造时内层是常数就当场算出来 |

* **不透明项的常数求值**与 `replay.py` 的 `mk_opaque` 相同：`div` / `mod` 取**向下取整**（Python 的 `//`、`%`，非负时与 C 相同）；
  `wrapN(c)` = `c mod 2^N`（非负）；`mul(x, y)` 只有两边都是常数才算——显式写的 `mul(2, p0)` 保持不透明（与 `2*p0` 不同，同 `replay.py`）。
* **溢出**：系数、常数的加、减、乘溢出 int64 时，整个式子变成**未知**（`IsUnknown()`，打印为 `?`）。D-21 的"溢出则整式降为不透明项"由此实现；
  未知在引擎里只会导向 SUSPECT。整数字面量超出 int64 同样得到未知。

### 2.2 规范形式（D-21）

原子按（组, 下标, 文本）排序：`pN`（组 0，下标 N）→ `pN->…`（组 1，下标 N）→ `ext(…)`（组 2）→ `g:…`（组 3）→ 其它符号（组 4，调用方局部）→
不透明项（组 5，按它的规范文本）；常数最后。打印：系数 1 省略、−1 写 `-x`、其余 `c*x`；后面的项是负的写 ` - `，否则 ` + `；
常数为 0 且有别的项时不写（`16*p1 - 12`、`ext(p0) - 4*p1 - 4`、`0`）。**两条式子相等当且仅当规范形式相同。**

### 2.3 解析（D-21 语法，同 `replay.py` 的 `Parser`）

```
expr   := ['-'] term (('+' | '-') term)*
term   := factor ('*' factor)*        至多一个非常数因子；两个都不是常数时成为 mul(a, b)
factor := INT | '(' expr ')' | 'ext(' name ')' | op '(' expr [',' expr] ')' | name
name   := IDENT [':' IDENT] ('->' IDENT)*
op     := 'div' | 'mod' | 'wrap32' | 'wrap16' | 'mul'
INT    := 十进制 | 0x 十六进制
```

`div` / `mod` 的第二个参数必须是常数且非 0。解析失败返回错误（带位置），不 `assert`（A-96）。

### 2.4 条件

`ParseCond("a <= b")` → 若干个"`L ≤ 0`"原子（同 `replay.py` 的 `C`）：`<=` → `[a − b]`、`<` → `[a − b + 1]`、`>=` → `[b − a]`、`>` → `[b − a + 1]`、
`==` → `[a − b, b − a]`。比较符取字符串里第一个（`->` 里的 `>` 不算）。`ShowLe0(L)` 打印回可读的不等式（同 `show_atom_le0`）：
没有正项时 `<负项> >= <k>`，否则 `<正项> <= <负项> - k`。

### 2.5 代换（A-61，同 `replay.py` 的 `subst`）

`Substitute(e, m)`：`m.sym`（符号名 → 式子）、`m.ext`（`ext(名)` 的名 → 式子）、`m.alias`（被调者形参名 → 调用方形参名，用于 `p0->f` →
`p2->f` 这种"实参就是调用方的形参"的改写）。不透明项里面也代换，代换后内层成了常数就当场算出来。

## 3. 对召回与误报的影响

没有判定逻辑。溢出、超大字面量一律成为未知，未知以后只导向 SUSPECT。

## 5. 测试

* 单元测试 `oobsum/unittests/core/LinExprTest.cpp`：加减与乘常数、排序、打印规则、不透明项的常数求值（含负数的向下取整）、显式 `mul` 与 `2*x` 的区别、
